# Verification evidence

This directory preserves the detailed evidence produced while the modernization was developed and reviewed:

- `CLAIMS_LEDGER.md` maps release claims to their supporting checks.
- `TEST_TAXONOMY.md` records the test inventory and classification.
- `RISK_MAP.md` records accepted compatibility risks and mitigations.
- `REFUTER_EVIDENCE.md` records adversarial review outcomes.

Historical commit identifiers, internal work-order identifiers, and archived evidence paths in these documents refer to the private migration audit trail from which this clean public release snapshot was produced. The public repository's GitHub Actions workflow independently reruns the executable Maven, endpoint census, OpenAPI, and secret gates on every push.
